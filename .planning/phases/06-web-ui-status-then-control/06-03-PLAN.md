<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WS server → browser | Server pushes snapshot; browser renders it via Svelte template (auto-escaped) |
| Browser → DOM | Camera names and labels from config are rendered via Svelte templates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-A | XSS (Information Disclosure) | Svelte template rendering camera names | mitigate | Svelte's template system HTML-escapes all `{expression}` by default; never use `{@html}`; camera names come from operator-entered config, not untrusted external sources |
| T-06-03-B | Information Disclosure | WS snapshot exposed to browser | accept | Tally state and connection status are non-sensitive operational data; LAN-only tool with no authentication scope per REQUIREMENTS.md |
| T-06-03-C | Denial of Service | WS reconnect loop on persistent disconnect | accept | setTimeout(connect, 2000) is 2s flat — not exponential; for a LAN tool this is acceptable; tight loop risk is negligible with a 2s floor |
| T-06-SC | Tampering | npm packages | accept | No new packages in this plan — packages installed in Plan 01; no additional installs |
</threat_model>
