3. CSRF HOOK — register once at server level before routes:
   ```typescript
   fastify.addHook('onRequest', async (request, reply) => {
     if (['PUT', 'POST', 'DELETE'].includes(request.method)) {
       const secFetchSite = request.headers['sec-fetch-site'];
       if (secFetchSite && secFetchSite !== 'same-origin' && secFetchSite !== 'none') {
         return reply.code(403).send({ error: 'CSRF: cross-origin request rejected' });
       }
       const origin = request.headers['origin'];
       if (origin && !origin.startsWith(`http://${request.hostname}`)) {
         return reply.code(403).send({ error: 'CSRF: invalid origin' });
       }
     }
   });
   ```

   ```typescript
   function broadcast(snapshot: StateSnapshot): void {
     const msg = JSON.stringify(snapshot);
     for (const client of fastify.websocketServer.clients) {
       if (client.readyState === WebSocket.OPEN) {
         client.send(msg);
       }
     }
   }
   ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Fastify REST API | All PUT/POST/DELETE payloads cross here; must be validated |
| Cross-origin browser → API | CSRF threat: malicious page issues state-mutating requests |
| WS client → Server | Incoming WS messages from browser (push-only — ignored) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02-A | Tampering | PUT /overrides/:cameraId | mitigate | Zod body validation rejects values outside ['program','preview',null]; 400 returned on failure |
| T-06-02-B | Tampering | PUT /config/settings, PUT /config/mapping | mitigate | Full-document safeParse via existing schema rejects invalid host/port/mapping shapes; toConfigValidationError returned on 400 |
| T-06-02-C | Tampering | POST /test/:cameraId | mitigate | Zod enum validation on action field; invalid action → 400 |
| T-06-02-D | Tampering | CSRF — cross-origin PUT/POST/DELETE | mitigate | onRequest hook checks Sec-Fetch-Site header; Origin header as fallback; 403 on cross-origin mutation |
| T-06-02-E | Tampering | WS incoming messages | accept | WS handler ignores all incoming messages (push-only channel per D-04); no state mutation from client WS |
| T-06-02-F | Denial of Service | GET /vmix/roster when vMix offline | accept | Returns empty array immediately; no blocking call; VmixConnector.roster() is in-memory Map |
| T-06-SC | Tampering | npm packages (already installed) | accept | All packages verified in RESEARCH.md Package Legitimacy Audit; no new installs in this plan |
