## Phase Goal

**As an** operator, **I want to** open a browser UI that shows my cameras and lets me control them,
**so that** I can monitor and manage tally state without touching a terminal.

<objective>
Lay the foundations for the Svelte 5 web UI build: split the TypeScript configuration so the
server (NodeNext) and frontend (bundler) compile contexts are fully isolated, create the Vite
build config, install the three missing devDependencies, extend the ConfigStore schema with the
backward-compatible `overrides` field (D-13), and create the Wave 0 test stub files that later
plans fill with assertions.

emit errors on browser-targeted code. This is the highest-risk setup step (RESEARCH.md Pitfall 1)
and must be done first so all subsequent plans build on a verified foundation.

Output: Clean `tsc --noEmit` on both configs, `vite build` exits 0, schema accepts optional
overrides, three test stubs committed.
</objective>
