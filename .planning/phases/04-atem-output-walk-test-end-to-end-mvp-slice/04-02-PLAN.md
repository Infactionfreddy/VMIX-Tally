## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → GET /walk-test | Unauthenticated GET from any host on the network. Triggers real ATEM hardware commands. LAN-only scope per REQUIREMENTS.md (authentication explicitly out-of-scope). |
| ConfigStore → server.ts bootstrap | PersistedConfig read at startup; settings.atem.host/port used for ATEM connection. Code-controlled path (default config.json); not from request payload. |
| server.ts → AtemConnector.walkTest | Internal in-process call; walks directly to hardware. isWalkRunning flag prevents concurrent calls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Tampering | GET /walk-test — unauthenticated, triggers real ATEM hardware commands | accept | LAN-only tool; REQUIREMENTS.md explicitly out-of-scope for authentication. Primary risk is accidental production trigger. isWalkRunning (D-11) prevents concurrent runs. Document operator procedure: run walk-test before going live only. |
| T-04-07 | Denial of Service | GET /walk-test — repeated calls queue up hardware commands | mitigate | isWalkRunning flag (D-11) returns 409 on concurrent calls. A single walk-test occupies ~(N_cameras × 4) seconds then resets the flag. No queuing. |
| T-04-08 | Elevation of Privilege | walk-test endpoint accessible beyond LAN (Fastify on 0.0.0.0) | accept | Production network operator responsibility (firewall/router). REQUIREMENTS.md explicitly out-of-scope for auth/network hardening. Logged as a known limitation. |
| T-04-09 | Tampering | TallyOrchestrator stateChanged wiring in server.ts — wrong payload shape breaks applyState | mitigate | TypeScript strict types enforce payload shape: `{ newState: ResolverOutput, tallyReceivedAt: number }` — compiler rejects mismatches at `tsc --noEmit`. |
| T-04-10 | Information Disclosure | Fastify error response leaks stack traces | mitigate | Fastify 5 with pino logger: error responses include only code+message in production mode (no stack traces). pino structured logs go to stdout/operator, not HTTP response. |
| T-04-SC | Tampering | npm install fastify (Fastify already installed from Phase 3) | accept | Fastify 5.9.0 already installed and slopcheck-clean (04-RESEARCH.md §Package Legitimacy Audit). No new installs in Plan 02. |
