## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TallyOrchestrator 'stateChanged' → AtemConnector.applyState | ResolverOutput arrives from the in-process resolver; trusted (pure function output). tallyReceivedAt is a plain timestamp integer — not user-controlled. |
| AtemConnector → atem-connection Atem | Commands sent over Ethernet to ATEM hardware. Host/port come from ConfigStore (code-controlled); not from external request payloads. |
| walkTest loop → ATEM hardware | Sequential hardware commands triggered by a background task initiated via HTTP (see Plan 02 for the HTTP boundary). |
