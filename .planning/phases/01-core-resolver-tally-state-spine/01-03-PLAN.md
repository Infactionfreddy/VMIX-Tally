<objective>
Implement the single-writer diff reconciler: the Core component that OWNS the
last-sent desired ATEM bus state and emits an ATEM command intent only when the
freshly-resolved desired state differs from what was last sent (D-03, CORE-03).
No-op-on-unchanged is a first-class, tested behavior (SC4), not an optimization.

Purpose: Pitfall 7 (command thrash) and CORE-03 require that no redundant ATEM
command ever hits the wire. Centralizing last-sent ownership in the Core (not in a
downstream connector) is the locked architectural decision (D-03, ARCHITECTURE
Pattern 1) and is what makes resync-after-reconnect trivial in Phase 5 (just
re-assert desired). This plan builds the diff engine; Phase 4 wires its per-field
change report to changeProgramInput/changePreviewInput.

Output: src/core/tallyState.ts exporting a TallyStateReconciler that holds the
last-sent DesiredAtemBusState and, on submit(desired), returns a per-field change
report and emits only on real change; plus a test suite proving diff, no-op, and
null-transition behavior.
</objective>
