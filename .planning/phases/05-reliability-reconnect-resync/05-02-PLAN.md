## Phase Goal

**As a** production operator, **I want** the bridge to reconnect to the ATEM automatically after a network drop and immediately re-assert the correct camera tally, **so that** cameras show the right red/green state after recovery without operator intervention.

<objective>
Add exponential backoff reconnect to AtemConnector, emit a 'ready' event on every
successful hydration (initial connect + every reconnect), and wire server.ts to
re-assert current desired state on 'ready'. The needsResync flag + reconciler.reset()
ensures the ATEM always receives commands after reconnect even if desired state is
unchanged from pre-disconnect.

Purpose: ATEM-04 — server survives ATEM cable pulls mid-show and restores correct
tally automatically (D-01, D-02, D-03 from 05-CONTEXT.md).

Output: Updated AtemConnector.ts with 'disconnected' backoff + 'ready' event;
extended AtemConnector.test.ts with ATEM-04 behavior tests; server.ts with
'ready' re-assert listener.
</objective>
